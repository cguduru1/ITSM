# 🖥️ ITSM Desktop Application

A Windows desktop application that combines a **React frontend** and a **Node.js backend** using **Electron**.  
This project provides a unified IT Service Management (ITSM) experience with modules for **Tickets, Assets, Procurement, Changes, CMDB, and Knowledgebase**.

---

## 📸 Features

🎫 Ticket Management (Incidents, Service Requests, Problems)

💻 Asset Inventory & Lifecycle

📦 Procurement & Purchase Orders

🔄 Change Requests (Normal, Standard, Emergency)

🗂️ CMDB Quantum Dashboard

📚 Knowledgebase with AI Insights

## 🚀 Installation

1. Go to the [Releases](https://github.com/cguduru1/ITSM/releases) page.
2. Download the latest `setup.exe`.
3. Run the installer and follow the wizard.
4. Launch the app from the Start Menu or Desktop shortcut.
