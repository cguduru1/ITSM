# 🚀 ITSM Project

A Windows application built with ITSM containing Ticket, Assets, Procurement, Changes, CMDB and Knowledge modules.

## 📦 Installation
1. Download the latest release from [Releases](https://github.com/cguduru/ITSM/releases).
2. Run the `setup.exe` (or `.exe`) file.
3. Follow the installation wizard.
